### Dependencies among tasks 27-34

No hard logical dependencies exist between these tasks: every one's Prerequisites are satisfied entirely by the
completed 01-26 base, so no new task blocks another. The High-to-Low severity order is therefore a valid execution
order, not a required one — any order works. The only couplings are shared files (a merge concern, not a logical
dependency):

| Shared file | Tasks that modify it |
|-------------|----------------------|
| `cmd/control/main.go` (route/startup wiring) | 27, 28, 29, 30, 31, 32 |
| `internal/control/dispatcher.go` | 27, 28, 32 |
| `internal/control/admin_handlers.go` | 29, 30 |
| `internal/control/config_admin_handlers.go` | 30, 31 |
| `internal/control/request_metadata.go` | 28, 32 |

Work these serially, or expect a rebase if they are branched in parallel. Tasks 33 and 34 touch no shared files and
can run at any time.

Tasks marked done before the audit are done for their (narrow) library scope only. The audit corrections in
`docs/agents/handoffs/05-*.md`, `docs/agents/handoffs/11-*.md`, and task 03's unchecked wiring step record
where the original claims overstated integration.

## Rules

- Start from `AGENTS.md`.
- Read the task file before editing.
- Do not skip prerequisites.
- Run `make check` before handoff.
- Use `docs/agents/templates/handoff.md` for handoff.
- Follow the Completion Audit in `.llm-docs/skills/straw-task-runner/SKILL.md`: a wiring step is only done when
  the built binary constructs the real component, and every deferral must name the owning task file.
