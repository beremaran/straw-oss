## Rules

- Start from `AGENTS.md`.
- Read the task file before editing.
- Do not skip prerequisites.
- Run `make check` before handoff.
- Use `docs/agents/templates/handoff.md` for handoff.
- Follow the Completion Audit in `.claude/skills/straw-task-runner/SKILL.md`: a wiring step is only done when
  the built binary constructs the real component, and every deferral must name the owning task file.

## Notes

- Tasks 01, 05, 12, and 17 are decision-gated by named entries in `docs/planning/32-open-decisions.md`.
- Tasks 13, 15, and 16 are conditional and may close as not-applicable depending on decisions or task 14's spec.
- `docs/planning/30-testing-matrix.md` requires MITM, BodyRef, payload-capture, Provider Adapter, and HTTP/2 test rows
  before those features ship; each task must add the rows it needs.
