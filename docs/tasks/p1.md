## Rules

- Start from `AGENTS.md`.
- Read the task file before editing.
- Do not skip prerequisites.
- Run `make check` before handoff.
- Use `docs/agents/templates/handoff.md` for handoff.
- Follow the Completion Audit in `.llm-docs/skills/straw-task-runner/SKILL.md`: a wiring step is only done when
  the built binary constructs the real component, and every deferral must name the owning task file.

- Tasks 01, 11, and 16 are spec-first because the planning docs explicitly leave important behavior undefined.
- Tasks 06 and 15 are blocked by named entries in `docs/planning/32-open-decisions.md`.
- Tenant-authored fingerprint profiles and redirect following are deliberately not tasked here pending owner decisions.
- Tasks 22 and 23 adopt two previously unowned deferrals surfaced by the 2026-07-05 P0 audit. Task 22 owns the
  egress credential config flat-vs-nested doc/code mismatch flagged in
  `docs/agents/handoffs/35-worker-registration-replay-and-identity-key.md`. Task 23 owns the multi-Control durable
  cancellation gap flagged in `docs/agents/handoffs/27-admin-request-cancellation.md`; it is gated on a committed
  multi-Control-replica decision and stays not-started as the registered owner until then.
