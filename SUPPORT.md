# Support policy

Straw is a maintainer-supported, pre-1.0 project. Usage questions and reproducible bug reports belong in
[GitHub issues](https://github.com/beremaran/straw-oss/issues). Security reports follow [SECURITY.md](SECURITY.md).

The latest release and `main` are supported. Maintainers aim to acknowledge security reports within five business
days and ordinary actionable issues within ten business days; these are targets, not a paid service-level agreement.
Releases are made when a coherent, verified change set is ready rather than on a fixed calendar.

Include the Straw version, deployment profile, OS/architecture, sanitized configuration, relevant health output, and
minimal reproduction. Never attach tokens, request URLs, headers, bodies, signed receipt URLs, or production logs.
