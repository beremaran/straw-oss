# Governance

Straw is currently maintained by Berke Arslan. Maintainers triage issues, review changes, make releases, handle
security reports, and protect the product boundary described in `README.md` and the architecture decisions.

Routine decisions happen in issues and pull requests. Durable changes to trust boundaries, required services,
protocol compatibility, or persistence require an architecture decision record. The maintainer seeks technical
consensus; if consensus is not possible, the maintainer records the decision and rationale. Anyone may appeal with
new evidence in the original issue. Conduct concerns follow `CODE_OF_CONDUCT.md`.

Maintainer status is earned through sustained, trustworthy contributions and explicit public appointment. There are
no implied commit, release, or security-response rights. Repository ownership rules are added only when a real,
available reviewer can own the path.
